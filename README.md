# Stellar Burger API Tests

Автотесты для проверки API проекта **Stellar Burger** — сервиса заказа бургеров.

Тесты написаны на `pytest` с использованием `requests` для отправки запросов и `Allure` для формирования отчётов.

## Стек технологий

- Python 3.10
- pytest
- requests
- Allure
- Faker (генерация тестовых данных)

## Структура проекта

```
.
├── conftest.py                    # общие фикстуры (создание/удаление пользователя)
├── handlers.py                    # эндпоинты API
├── urls.py                        # базовый URL сервиса
├── user_data.py                   # генерация и наборы тестовых данных пользователя
├── ingredients_data.py            # тестовые данные ингредиентов
├── test_create_user.py            # тесты создания пользователя
├── test_login_user.py             # тесты авторизации пользователя
├── test_change_user_data.py       # тесты изменения данных пользователя
├── test_create_order.py           # тесты создания заказа
├── test_get_orders_for_user.py    # тесты получения заказов пользователя
├── requirements.txt               # зависимости проекта
└── README.md
```

## Покрытые эндпоинты

| Метод  | Эндпоинт              | Описание                          |
|--------|------------------------|------------------------------------|
| POST   | `/api/auth/register`   | Создание пользователя              |
| POST   | `/api/auth/login`      | Авторизация пользователя           |
| PATCH  | `/api/auth/user`       | Изменение данных пользователя      |
| DELETE | `/api/auth/user`       | Удаление пользователя              |
| POST   | `/api/orders`          | Создание заказа                    |
| GET    | `/api/orders`          | Получение заказов пользователя     |

## Установка

1. Клонировать репозиторий:
   ```bash
   git clone <repository_url>
   cd <repository_folder>
   ```

2. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Linux / macOS
   venv\Scripts\activate      # Windows
   ```

3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск тестов

Запуск всех тестов:
```bash
pytest
```

Запуск с формированием Allure-отчёта:
```bash
pytest --alluredir=allure-results
allure serve allure-results
```

Запуск конкретного файла с тестами:
```bash
pytest test_create_user.py
```

## Тестовые сценарии

**Создание пользователя**
- успешная регистрация уникального пользователя
- регистрация уже существующего пользователя
- регистрация с незаполненными обязательными полями

**Авторизация**
- успешная авторизация под существующим пользователем
- авторизация с неверным логином/паролем

**Изменение данных пользователя**
- изменение email/password/name авторизованным пользователем
- попытка изменения данных без авторизации

**Создание заказа**
- создание заказа авторизованным и неавторизованным пользователем
- создание заказа без ингредиентов
- создание заказа с невалидным хешем ингредиента

**Получение заказов**
- получение заказов авторизованным пользователем
- получение заказов без авторизации
